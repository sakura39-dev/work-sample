# Web Designer Portfolio

バックエンドエンジニア出身のWebデザイナーによる限定公開ポートフォリオサイトのリポジトリです。
※本サイトは検索避け（noindex）を設定した限定公開サイトです。

## 💡 本プロジェクトの目的・こだわり
ただデザインを作るだけでなく、「その後の開発・運用のしやすさ」を意識したフロントエンドの構築を目指しました。

- **Jekyllを用いたコンポーネント化とデータ管理:**
  各実績やスキルセットの情報は `_data/` 内のYAMLファイルで一元管理しています。HTML構造を汚さず、将来的な実績追加や修正が容易な設計（DRY原則）にしています。
- **アクセシビリティとモダン仕様への配慮:**
  バナーモーダルの開閉制御には、最新のブラウザ標準である `inert` 属性を採用し、スクリーンリーダーやキーボードフォーカスが破綻しないようアクセシビリティを考慮しています。
- **バニラJSによる軽量なギミック実装:**
  レタッチ写真のBefore/After比較スライダーは、外部ライブラリに依存せず、CSSの `clip-path` と素のJavaScriptのみで自作し、軽量かつサクサク動くUIを実現しました。

## 🛠️ 技術スタック
- **SSG:** Jekyll
- **Design Tools:** Figma, Photoshop, Illustrator
- **Frontend:** HTML5, CSS3 (手書き / CSS変数活用), JavaScript (Vanilla JS)
- **Dev Tools:** Git / GitHub, VS Code, Docker

## 📂 ディレクトリ構造
```text
├── _data/              # 実績やスキルのデータをYAMLで管理
├── _includes/          # 各実績セクションをコンポーネント単位でモジュール化
├── _layouts/           # 共通レイアウト
├── _sass/              # SCSSの設計・コンポーネント用ファイル
└── assets/
    ├── css/style.css   # _sassからインポート・ビルドされるメインCSS
    └── js/main.js      # スライダーやモーダルを制御するバニラJS
```
